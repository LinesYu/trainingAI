## 🇻🇳 TIẾNG VIỆT: BIẾN AI THÀNH ĐỒNG ĐỘI "CHẤT CHƠI"

Bạn có mệt mỏi khi AI (Cursor, Windsurf, Trae...) hay quên trước quên sau? Code lúc thì ngon, lúc thì "ngáo"?
Chào mừng bạn đến với **HỆ ĐIỀU HÀNH HÀNH VI** dành cho AI Agent. Đây không chỉ là prompt, đây là **LINH HỒN** giúp AI có kỷ luật, có trí nhớ và có... lương tâm.

### 🚀 TẠI SAO BẠN CẦN CÁI NÀY?

1.  **Kỷ Luật Thép**: AI sẽ không dám `any` lung tung, không dám sửa code mà không hiểu.
2.  **Trí Nhớ Dai**: Với cơ chế `SESSION_HISTORY` và `BRAIN_SYNC`, AI sẽ nhớ dai như người yêu cũ.
3.  **Lương Tâm (Conscience)**: AI biết sợ sai nhờ `LESSON_LEARNED` và `TRUST_SCORE`.
4.  **Phong Cách Riêng**: Phiên bản Tiếng Việt cực kỳ hài hước, gần gũi ("Sếp", "Em", "Ăn hành", "Ra đảo").

### 📂 CẤU TRÚC KHO TÀNG (FOLDER `VI`)

| File | Chức năng (Role) | Mô tả "Chợ Búa" |
|------|------------------|-----------------|
| `AGENTS_TEMPLATE_VN.md` | **Hiến Pháp** | Luật rừng. AI đọc xong là ngoan như cún. |
| `LESSONS_LEARNED_TEMPLATE_VN.md` | **Lương Tâm** | Cuốn sổ ghi thù. Ghi lại mấy cái ngu để không lặp lại. |
| `SESSION_HISTORY_TEMPLATE_VN.md` | **Trí Nhớ** | Nhật ký đời tôi. Để mai làm tiếp không bị ngáo. |
| `TRUST_SENTINEL_TEMPLATE_VN.md` | **Ví Tiền & Uy Tín** | Điểm tín nhiệm. Làm sai trừ điểm, làm tốt cộng điểm. |
| `POST_MORTEM_TEMPLATE_VN.md` | **Khám Nghiệm** | Biên bản hiện trường mỗi khi web sập. |
| `SKILL_WORKFLOW_TEMPLATE_VN.md` | **Tuyệt Chiêu** | Bí kíp võ công cho mấy việc khó nhằn. |

### 🛠️ CÁCH DÙNG (DỄ NHƯ ĂN KẸO)

1.  Vào thư mục `VI`.
2.  Copy toàn bộ file vào thư mục `.agent/` (hoặc `.cursorrules`, `.windsurfrules` tùy IDE của bạn).
3.  Đổi tên bỏ chữ `_TEMPLATE_VN` đi (ví dụ: `AGENTS.md`).
4.  Mở `AGENTS.md` lên và thay thế `[TÊN_BẠN]`, `[DỰ_ÁN]`...
5.  Tận hưởng cảm giác làm "Sếp" thực thụ!

## 🇺🇸 ENGLISH: THE PROFESSIONAL AI AGENT FRAMEWORK

Tired of AI losing context? Generating buggy code? Breaking your production build?
Welcome to the **EXTERNAL BRAIN** for AI Agents. This framework provides Structure, Memory, and Conscience to your LLM-based coding assistants (Cursor, Windsurf, Trae).

### 🚀 WHY DO YOU NEED THIS?

1.  **Enforced Discipline**: AI follows strict engineering standards (Atomic Edits, No `any`, RPM).
2.  **Persistent Context**: Mechanisms like `SESSION_HISTORY` ensure the AI remembers past decisions.
3.  **Self-Correction**: The `LESSON_LEARNED` system prevents the AI from repeating the same mistakes.
4.  **Professional Workflow**: Based on real-world Senior Engineering practices (Post-Mortems, RFCs, Architecture Reviews).

### 📂 THE ARSENAL (FOLDER `EN`)

| File | Role | Description |
|------|------|-------------|
| `AGENTS_TEMPLATE.md` | **Constitution** | The core laws and persona of the Agent. |
| `LESSONS_LEARNED_TEMPLATE.md` | **Conscience** | A log of anti-patterns and past failures to avoid. |
| `SESSION_HISTORY_TEMPLATE.md` | **Memory** | Session logs to maintain context across days. |
| `TRUST_SENTINEL_TEMPLATE.md` | **Resources** | Tracks "Trust Score" and API usage/limits. |
| `POST_MORTEM_TEMPLATE.md` | **Analysis** | Template for analyzing critical incidents. |
| `SKILL_WORKFLOW_TEMPLATE.md` | **Skills** | Standard Operating Procedures (SOPs) for complex tasks. |

### 🛠️ HOW TO USE

1.  Navigate to the `EN` folder.
2.  Copy the files to your project's `.agent/` directory (or configure as `.cursorrules` / `.windsurfrules`).
3.  Rename files to remove `_TEMPLATE` suffix (e.g., `AGENTS.md`).
4.  Customize `AGENTS.md` with your project specifics (Stack, Name, Rules).
5.  Start coding with a Senior AI Partner!
