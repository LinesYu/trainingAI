# BIÊN BẢN KHÁM NGHIỆM TỬ THI (SỰ CỐ)

Template này dùng để mổ xẻ mấy cái bug to tổ bố, sập web, hoặc những sự cố "nhớ đời".
**BẮT BUỘC**: Viết mỗi khi có biến căng. Để lần sau không "chết" vì cùng một lý do.

## 🔴 TÓM TẮT THẢM HỌA
- **Ngày**: [YYYY-MM-DD]
- **Giờ**: [HH:MM] (Giờ hoàng đạo hay giờ hắc đạo?)
- **Thời gian chết**: [Bao lâu thì web sống lại?]
- **Mức độ**: [Sập toàn bộ / Sập một phần / Khách chửi um sùm]
- **Thiệt hại**: [Bao nhiêu user bị ảnh hưởng? Tính năng nào đi đời?]

---

## 🔍 TRUY TÌM THỦ PHẠM (5 CÂU HỎI TẠI SAO)
1. **Tại sao nó xảy ra?**
   - [Trả lời thật lòng đi]
2. **Tại sao lại thế?**
   - [Đào sâu hơn]
3. **Tại sao nữa?**
   - [Đào tiếp]
4. **Vẫn là tại sao?**
   - [Sắp ra vấn đề rồi]
5. **Nguyên nhân gốc rễ là gì?**
   - [Chốt hạ: Do code ngu, do server yếu, hay do định mệnh?]

---

## 🛠️ CẤP CỨU & HỒI SỨC
- **Sơ cứu ngay**: [Làm gì để web chạy lại tạm thời?]
- **Chữa dứt điểm**: [Phải làm gì để nó không bao giờ quay lại?]
- **Code đã sửa**: [Link tới PR hoặc commit cứu thế]

---

## 🛡️ KẾ HOẠCH PHÒNG THỦ (RÚT KINH NGHIỆM)
- **Cái gì đã làm tốt?**: [Có backup không? Rollback có nhanh không?]
- **Cái gì đã làm sai?**: [Test chưa kỹ? Deploy liều mạng?]
- **Hành động cụ thể**:
    1. [Viết thêm test case cho trường hợp này]
    2. [Sửa lại tài liệu hướng dẫn]
    3. [Refactor cái đống code spaghetti kia]

---

## 🧠 CẬP NHẬT BỘ NHỚ
- **Luật Mới**: [Thêm điều gì vào AGENTS.md hoặc LESSONS_LEARNED.md?]
- **Skill Mới**: [Cần thêm bước kiểm tra nào vào quy trình?]
